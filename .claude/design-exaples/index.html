DESIGN SYSTEM · VERSION 1.0

Claude System

A quiet, editorial design system for building consistent pages. Install it on Windows, macOS, or Linux via curl, npm, or pip — then pick a path below.

Install ↓ View systems ↓ Open docs ↗
01 — Install

Get started

win · mac · linux
via curl (PowerShell)
terminal
curl -fsSL https://raw.githubusercontent.com/hariomlohardev/claude-system/main/install.ps1 -o install.ps1
powershell -ExecutionPolicy Bypass -File install.ps1
via npm
terminal
npm install -g claude-system
via pip
terminal
pip install claude-system
via curl
terminal
curl -fsSL https://raw.githubusercontent.com/hariomlohardev/claude-system/main/install.sh | bash
via npm
terminal
npm install -g claude-system
via pip
terminal
pip install claude-system
via curl
terminal
curl -fsSL https://raw.githubusercontent.com/hariomlohardev/claude-system/main/install.sh | bash
via npm
terminal

via pip
terminal
