Contributing

Prerequisites

  • Node >=18 and npm
  • git and GitHub account

How to contribute

cp -r template/starter-system systems/my-system
# edit system.json, CLAUDE.md, README.md
npm --prefix cli run build
node cli/dist/index.js validate systems/my-system

PR flow

CI validate.yml must be green before merge.
