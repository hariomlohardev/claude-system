CLI Reference

10 commands — list → search → info → install → run. Keep the CLI thin; what can be a System, build as a System.

Global flags: --help --version themed via commander · store ~/.claude-system/systems/<name>/ + systems.json

list

List Systems from the registry or only installed ones.

claude-system list [--installed|--available] [--category <cat>] [--json]

Always fresh — Cache-Control: no-cache · /api/registry → raw.githubusercontent fallback. Category filter: --category open-source.

search

Keyword search over name, displayName, description, keywords.

claude-system search <query>

Live via /api/search?q= (Supabase search_vector + pg_trgm). Try claude-system search frontend or Browse filtered.

info

Show manifest, permissions, links, and install status for one System.

claude-system info <system>

Shows permissions[] and setup.sh note — read before install. Example: claude-system info example-system → view.

install

Copy to ~/.claude-system/systems/<name>/ and record in systems.json. Fires POST /api/systems/:name/install for downloads.

claude-system install <system>

remove

Remove the System and its entry in systems.json.

claude-system remove <system>

update

Update to latest registry version (preserves setupDone).

claude-system update [<system>|--all]

Shows permission escalation diff if new permissions[] added.

run

Open claude inside the System. First run shows # WHY: and asks y/N; on exit 0 sets setupDone.

claude-system run <system> [-- <args>]

Forwards -- <args> to claude — e.g. claude-system run example-system -- --help.

create

Scaffold systems/<name>/ from template/starter-system.

claude-system create <name>

kebab-case · name === folder enforced by CI.

validate

Validate system.json + name===folder + required files + security.

claude-system validate [path]
node cli/dist/index.js validate systems/<name>

report & doctor

Open tracker's issue page (bugs.url → repository/issues → monorepo).

claude-system report <system>
claude-system doctor
claude-system --help --version

Source is cli/src/commands/*.ts — 10 commands, thin CLI, System/Skill/plugin rule.
