Security & trust

Permissions are declared, setup.sh needs a WHY, and consent is once-only — explicit, not implied.

v1.0·9 sections·updated 2026

Permissions — honest by design#

Every system.json declares permissions[] honestly. Six values, unique, strict:

PermissionMeaning
filesystem:readRead files — muted badge
filesystem:writeWrite files
network:readRead network
network:writeWrite network
shell:execRun shell — accent border
credentials:readRead credentials — accent soft warning

setup.sh — once-only consent#

setup.sh must start with # WHY: explaining what it does. On first claude-system run <name> we echo that WHY, ask y/N (non-TTY → false), and on approval set setupDone:true in ~/.claude-system/systems.json. Exit 1 on N.

setup.sh
# WHY: install deps for example-system
npm ci
Warning

Never silently grant permissions. See cli/src/lib/setupRunner.ts — promptConsent is explicit.
