What is a System

A System is a versioned bundle of CLAUDE.md, skills, agents, commands, hooks, MCP and config. Installed to ~/.claude-system/systems/<name>/ and run via claude-system run <name> which shells out to the real claude CLI.

Manifest

system.json validates against schemas/system.schema.json — strict, additionalProperties false. Required: name (kebab, == folder), displayName, version semver, description, keywords, author, license, claudeSystem.specVersion, permissions[].

Registry

registry/index.json is generated from systems/*/system.json via scripts/generate-index.js. Never hand-edit. CLI fetches /api/registry (Supabase) with fallback to raw GitHub.
