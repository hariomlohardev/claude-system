STEP 01

Validate — before you ship

Every system.json must pass validate.yml: schema, name===folder, required files, no unsafe hooks.

  • claude-system validate locally
  • PR checks must be green before merge
  • additionalProperties: false
  • Permissions declared honestly
Run
terminal
npm --prefix cli run build && node cli/dist/index.js validate

Good for: catching mismatches before CI does.

STEP 02

Install — one command

Fetch the CLI via curl | sh at https://claude-system-tau.vercel.app/install, then install any System in one shot.

  • claude-system list + search — live
  • claude-system info <name> — permissions + WHY
  • claude-system install <name> → ~/.claude-system/
  • Consent y/N on first run
Try
terminal
curl -fsSL https://claude-system-tau.vercel.app/install | sh
claude-system install example-system
claude-system run example-system -- help

Note: setup.sh runs once-only — you’ll see # WHY: before you approve.

STEP 03

Run — shells out

Systems don’t replace Claude Code — they prepare an environment and shell out to the real claude CLI. Thin, honest, no chat runtime.

  • claude-system run <name> -- <args>
  • Forwards -- <args> to claude
  • setupDone persisted — run again just calls claude
  • Keep CLI thin — features belong in a System
Example
terminal
claude-system run example-system -- --help

Trust: info shows permissions before you install.
