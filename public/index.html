02 — About

Install a workflow, not plugins

Curated · Versioned · Reviewed

A System is a versioned bundle of CLAUDE.md, skills, agents, commands, hooks, and config that together form a reproducible Claude Code environment. One curl | sh, one claude-system install, and you run claude inside the System — not around it.

This project does not replace Claude Code. It prepares the environment and shells out to the real claude CLI. Stable, boring, honest — like a printed ledger.

05 — Install

One line to start

Node ≥18 · claude CLI

Primary install is via Vercel — plain text, auditable. Thin wrappers on npm and pip delegate to the same CLI.

curl -fsSL https://claude-system-tau.vercel.app/install | sh
# then
claude-system list
claude-system search <keyword>
claude-system install <name>
claude-system run <name>
npm i -g claude-system
claude-system list
claude-system install <name>
claude-system run <name>
pip install claude-system
claude-system list
claude-system install <name>
claude-system run <name>

Fallback: curl -fsSL https://raw.githubusercontent.com/hariomlohardev/claude-system/main/install.sh | sh · CLI reference → · store ~/.claude-system/systems/<name>/

07 — FAQ

Answers in brief

Is this a replacement for Claude Code? ›

No. It is a Systems layer around the real claude CLI. Every run shells out to claude inside the installed System.

What must a System contain? ›

system.json + CLAUDE.md + README.md under systems/<name>/, with name === folder. Optional skills/, agents/, commands/, hooks/, settings.json.

How are permissions handled? ›

permissions[] is self-declared and reviewed, not sandboxed at runtime. See Security — read them with the same care as any package.

What about setup.sh? ›

If present it must have # WHY:, declares shell:exec, and is gated by a y/N prompt on first run. Only on exit 0 is setupDone set.

How is the registry served? ›

Generated from systems/*/system.json → registry/index.json → synced to Supabase. Clients fetch /api/registry (Vercel, s-maxage=60) with fallback to raw.githubusercontent.com.
