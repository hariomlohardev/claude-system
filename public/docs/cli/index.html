Overview#

The claude-system binary scaffolds, previews, builds, and verifies systems. All commands are run from a project root unless noted. Get help for any command with --help.

Command index

CommandPurposeKey flags
listList available / installed--installed --category
searchSearch registry<query> --category
infoShow manifest + perms<name>
installInstall to ~/.claude-system<name>
runRun via real claude<name> -- <args>
removeRemove installed<name>
createScaffold a System<name>
validateValidate system.json[path]
get help
claude-system --help            # all commands
claude-system build --help      # help for one command
claude-system --version         # print version

list#

claude-system init <dir> [flags]

Scaffolds a new project in <dir>. Creates the folder structure, a starter claude-system.config.json, and src/tokens.css.

FlagDescription
--blankScaffold with no starter pages.
--template <name>Seed with a page template (editorial, ledger, notebook, docs).
-y, --yesAccept all defaults without prompting.
examples
claude-system init my-site
claude-system init my-site --template editorial
claude-system init my-site --blank -y
Note

If <dir> already exists and isn't empty, init aborts unless you pass --force.

search#

claude-system new <name> [flags]

Creates a new system or component inside the current project. By default it creates a system; use --type to create a component instead.

FlagDescription
--type <kind>What to create: system (default) or component.
--template <name>Base the new item on a built-in template.
--blankCreate an empty scaffold with no content.
examples
claude-system new editorial                    # a system from a template
claude-system new landing --template editorial
claude-system new button --type component      # a single component
claude-system new my-system --blank            # empty, build it yourself

info#

claude-system serve [flags]

Starts a local dev server that reads src/ directly and hot-reloads on change. No build step required while iterating.

FlagDescriptionDefault
-p, --port <n>Port to listen on.4000
--host <addr>Host to bind.localhost
-o, --openOpen the browser on start.off
examples
claude-system serve
claude-system serve --port 8080 --open

install#

claude-system build [flags]

Builds the project into static, production-ready files in the output directory. Runs check first unless disabled.

FlagDescriptionDefault
-o, --out <dir>Output directory.dist
--minifyMinify CSS/JS.on
--no-minifySkip minification (readable output).—
--skip-checkDon't run the spec check before building.off
examples
claude-system build
claude-system build --out public --no-minify
Warning

The output directory is wiped and regenerated on every build. Never hand-edit files inside it.

run#

claude-system check [flags]

Lints every page against DESIGN.md — verifying tokens, contrast, typography, spacing, and component usage. Returns a non-zero exit code if anything is off-system.

FlagDescription
--strictTreat warnings as errors.
--format <fmt>Output format: text (default) or json.
--only <rule>Run a single rule (tokens, contrast, type, spacing).
example output
$ claude-system check
  ✓ tokens      all on-system
  ✓ contrast    all pairs ≥ AA
  ✓ typography  no off-spec fonts
  ✓ spacing     scale respected
  0 errors · 0 warnings
Tip

Add claude-system check --strict to your CI so every pull request is verified automatically.

list#

claude-system list [flags]

Shows what's available — built-in systems, templates, and the components in the current project.

FlagDescription
--systemsList built-in systems.
--templatesList page templates.
--componentsList components in this project.
example output
$ claude-system list --systems
  editorial   landing page system
  ledger      list / index system
  notebook    article / post system
  docs        documentation system

Exit codes#

CodeMeaning
0Success.
1General error (build failed, missing config).
2Usage error (unknown command or flag).
3Spec check failed (off-system output).

Config file#

All commands read claude-system.config.json at the project root. See the configuration guide for every key. A minimal example:

claude-system.config.json
{
  "name":   "my-site",
  "accent": "#B93A13",
  "paper":  "#F6F4EE",
  "build":  { "out": "dist", "minify": true },
  "pages":  ["index", "docs"]
}
