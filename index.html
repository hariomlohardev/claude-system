FAQ

What is a System? ›

A versioned bundle of CLAUDE.md, skills, agents, commands, hooks and config. Installed to ~/.claude-system/systems/<name>/.

Does it replace Claude Code? ›

No. It prepares an environment and shells out to the real claude CLI. No chat runtime.

How are permissions handled? ›

Each system.json declares permissions[] honestly. setup.sh must include # WHY: and is gated by a one-time consent prompt on first run.

How do I contribute? ›

Copy template/starter-system → systems/<name>/ → system.json → claude-system validate → PR. See Creating a System.

claude-system is a curated registry for Claude Code — minimal, warm, honest. No assistant bubble.
